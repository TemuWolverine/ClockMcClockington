Open Source ESP32 Clock

A reliable, open-source clock powered by ESP32, ESPHome and Home Assistant. 4 buttons to trigger Home Assistant automations, talk to it for some reason and it'll talk back.

This project provides the firmware and documentation needed to build or update your device.

Setup

Device Configuration

The temperature information is fetched from Home Assistant. You'll need to have the sensor preconfigured.
If you use the flashing tool above
Setup a template sensor
  1. Navigate (in Home Assistant) to Settings > Devices & Services > Helpers
  2. Create Helper (bottom right corner) > Template > Sensor
  3. Two fields are required, the name and the state. Name must be clock_temp

    Set the state to {% raw %}{{ states("sensor.myweathersensor_temperature")}}{% endraw %}

    The other fields are entirely optional, but can make presentation in HomeAssistant clearer


If you're installing from YAML
In the substitutions section, near the top of the clock.yaml file, find "weatherSensor" weatherSensor : sensor.clock_temp.
Change that to your sensor weatherSensor : sensor.my_super_local_sensor

Then compile and install on your ESP32

Button Automations

The way ESPHome exposes hardware buttons to Home Assistant is a bit funky (or I'm an idiot and have done it wrong) - they're exposed as generic events rather than 'click'.

ClockMcClockington sends out "esphome.<name>.clock_button_pressed", where name will start with 'clockmcclockington' plus the MAC of the device. The event data will be one, two, three or four. Currently long press and double click are not implemented.

Home Assistant Automations
alias: btnOne
description: ""
triggers:
  - trigger: event
    event_data:
      button: one
    event_type: esphome.clockmcclockingtonred.clock_button_pressed
conditions: []
actions:
  - action: light.toggle
    metadata: {}
    target:
      area_id: study
    data: {}
mode: single


Node-Red
The switch evaluates msg.payload.event.button, with the possible options being "one", "two", "three", and "four" (from left to right on the clock). You can then trigger whatever you want from there.
